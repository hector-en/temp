**Purpose:** this is the authoritative source-of-truth file for the first skeleton coding pass. Codex should use this file before any individual SPEC or RUN_INSTRUCTIONS files are generated.

**Scope:** implement the full platform skeleton first using folders, schemas, package-policy placeholders, dummy science outputs, adapter mappings, guarded live stubs, and smoke tests. Do **not** implement full science, real Runpod jobs, real Paperclip database writes, or uncontrolled model calls in this first pass.

**Core rule:** build the nervous system first, use fake organs, then replace each organ with real science or live platform code while keeping the same output contracts.

## Non-negotiable skeleton contracts

1. Every dummy science command writes the same filenames the real science will write later.
2. Agentfield, Paperclip, OpenClaw, and Publisher depend on output contracts, not internal science implementation.
3. Layer 4 reads selected notes/reports and suggests actions, but never overwrites the vault by default.
4. Runpod live execution stays explicit; dryrun is default.
5. Paperclip live submit/database writes stay explicit; mock/dryrun is default.
6. Human review is required before launching expensive campaigns, promoting mechanism claims, writing to Paperclip production state, or auto-approving next experiments.
7. Final pattern similarity is never sufficient evidence; mechanism evidence remains the platform success criterion.
